Împărțire cu și fără rest

Împărțire exactă și cu rest; verificarea \(D = Î\cdot C + R\).

Formula de bază

Pentru numere naturale: \(D = Î \cdot C + R\), cu \(0 \leq R < Î\).

Fără rest: \(R=0\), deci \(D\) e multiplu al lui \(Î\).

Cu rest: restul e strict mai mic decât împărțitorul.

Exemple

  1. \(56 : 7 = 8\) (rest 0): \(56=7\cdot 8\).
  2. \(50 : 7 = 7\) rest \(1\): \(50=7\cdot 7+1\).
  3. Verificare greșită dacă restul ≥ împărțitor.
