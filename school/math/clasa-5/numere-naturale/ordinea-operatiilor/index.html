Ordinea operațiilor

Paranteze rotunde, pătrate, acolade; ce faci primul.

Ordine

  1. Paranteze: rotunde ( ), apoi pătrate [ ], apoi acolade { }
  2. Puteri
  3. Înmulțiri și împărțiri (stânga → dreapta)
  4. Adunări și scăderi (stânga → dreapta)

Exemple

  1. \(3+4\cdot 5 = 3+20=23\) (nu 35).
  2. \([2+(7-3)]\cdot 5 = [2+4]\cdot 5=30\).
  3. \(2^3 \cdot 3 + 1 = 8\cdot 3 + 1=25\).
