## ⚡ Tech Stack & Architecture

Built with pure, artisanal web fundamentals:
- **Semantic HTML5** &bull; Clean markup, accessible structure.
- **Modern Vanilla CSS** &bull; EA SPORTS FC-inspired dark aesthetic, glowing neon accents, glassmorphic cards, fluid typography (`clamp()`), and responsive flexbox layouts for desktop & mobile.
- **Vanilla JavaScript** &bull; Real-time client-side clock engine, date formatter, and UNIX timestamp tracker. Zero dependencies, zero bloat.
- **GitHub Pages + `.nojekyll`** &bull; Pure static hosting bypassing Jekyll pipelines.
